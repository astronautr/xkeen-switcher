# Security policy

xkeen-switcher controls your router and stores its SSH password, so security reports are welcome.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/astronautr/xkeen-switcher/security/advisories/new), not in public issues. Include the affected version or commit, steps to reproduce and the impact you expect.

You should get a first response within a week. Fixes are released on `main`; there are no separately maintained versions.

## Scope and assumptions

The dashboard is designed for a trusted home LAN and serves plain HTTP. Exposing it to the internet is outside the supported setup; reports that rely only on that are still welcome as hardening suggestions.
